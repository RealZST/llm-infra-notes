# llm-infra-notes

Experiments and data behind the notes on [realzst.github.io/notes](https://realzst.github.io/notes/). Each folder belongs to one note and holds its benchmarks, the raw and processed measurements, the scripts that turn them into the note's numbers and figures, and the figures themselves, so every result can be checked against the data or re-run on other hardware.

| Note | Folder |
|---|---|
| The Roofline Model, Starting from Measured Data ([English](https://realzst.github.io/notes/roofline/) · [中文](https://realzst.github.io/notes/roofline/zh/)) | [roofline/](roofline/) |

## Layout

```
<note>/
  code/        benchmarks; scripts that summarize the measurements and draw the figures
  data/        processed tables the note quotes
  data/raw/    the per-sample records the processed tables are built from
  figures/     the note's figures, generated by code/plot.py
  README.md    what each file is and how to reproduce it
```

Measurements were taken on shared cluster GPUs and one local workstation. Host names, GPU UUIDs, job identifiers, paths and absolute timestamps were removed; GPU model, memory, SM count, L2 size and power limit are kept.
